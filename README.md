# The Dig public data feed

The Dig pools upcoming estate sales within about 25 miles of Friendswood, Texas. Each entry in `sales.json` lists shopping dates, available hours, a map location and links to the original listings. Dates and times use the America/Chicago time zone. An approximate point marks an area center. Check the original listing for the street address before traveling.

The file includes the collection time, the 14-day window and counts for each source. Cross-posted sales retain all their source links. A manual refresh replaces the snapshot. [Download the current JSON feed](https://raw.githubusercontent.com/rheinze08/the-dig-data/main/sales.json)

Some locations use data from [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
